# Saudação e lista de filmes

Dois exercícios de Portugol Studio: uma função que saúda o usuário em `saudacao.por` e um laço que percorre três filmes em `lista_de_filmes.por`.

## Como executar

No Portugol Studio 2.7.5, abra o arquivo `.por`, execute-o pelo botão ▶ e responda no console quando solicitado.

## Exemplos

| Programa | Entrada | Saída esperada |
|---|---|---|
| `saudacao.por` | `Ana` | `Olá, Ana! Seja muito bem-vindo(a)!` |
| `saudacao.por` | Linha vazia | `Nenhum nome informado.` |
| `lista_de_filmes.por` | Nenhuma | Três filmes numerados, de `1º Filme: O Auto da Compadecida` a `3º Filme: De Volta para o Futuro`. |
